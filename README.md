A Maths revision program for GCSE students.

Features:
- A section which consists of condensed notes of various maths topics, specifically aimed to help GCSE maths students revise, and get a grasp of any math topic they are struggling with
- A maths quizzing section, where the user is presented randomly selected, multiple choice GCSE maths questions. The aim is for the student to answer as many questions, without losing all three of their lives. After answering three questions incorrectly, the program presents a game over screen, showing the student their score.
